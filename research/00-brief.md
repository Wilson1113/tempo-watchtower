# World's Fair Research Brief (shared by all agents)

## The builder & the product
- Solo builder. Wants a **pure Rust product**: the Rust artifact IS the product (crate / CLI / daemon / node / SDK / VM / prover / plugin).
  NOT a web dApp with a thin Rust backend. Builder background should NOT drive idea selection.
- Domain: web3 **core infrastructure** in one of: **VM** (execution/runtime), **Async** (networking, runtimes, data pipelines, node infra), **Cryptography**.
- Strategy (lean): target a **niche, specific user group that everybody knows exists** but that big companies / foundations
  / well-funded teams won't serve because it's too specific. Start with a small, reachable set of target users.

## The hackathon: Colosseum "Crypto World's Fair"
- Online, multi-ecosystem. Contest period: 2026-09-14 06:00 PT -> **2026-10-12 23:59 PT**. Winners announced by 2026-12-05.
- **Today is 2026-09-24 -> ~18 days left.** The MVP must be buildable solo to demo quality in ~14 days (leave ~3-4 days for pitch video + demo video + polish).
- Prizes (Phantom CASH stablecoin):
  - Grand Champion $30k; next 20 standout teams $15k each; Public Goods Award $5k; University Award $5k.
  - Tracks ("best products that integrate with..."):
    - Solana $100k / 10 projects; Tempo $100k / 10; Hyperliquid (HyperCore or HyperEVM) $100k / 10; Zcash (blockchain or asset) $100k / 10
    - Ethereum L1 $25k / 5; Base $25k / 5; Arbitrum $25k / 5; Robinhood Chain $25k / 5
  - Accelerator: selected winners -> $250k pre-seed, 12-week in-person program in San Francisco.
- Judges: Colosseum team (Clay Robbins, Matty Taylor, Nate Levine, Max Monciardini, Michael Rinko) + 16+ track/ecosystem judges.
- Solo entrants allowed (Entrant = Individual; teams optional). One project submission per entrant.

## Official judging criteria (verbatim from rules §8)
(a) Functionality: How well does this Project Submission work? What is the quality of the code?
(b) Potential Impact: How big is the total addressable market for this Project Submission? What will be the impact of this Project Submission on the broader crypto ecosystem?
(c) Novelty: How unique is this Project Submission's concept?
(d) UX: How well does this Project Submission utilize blockchain to create great UX for downstream users?
(e) Open-source: Is this Project Submission open-source? How well does the Project Submission compose with other primitives in the crypto ecosystem?
(f) Business Plan: Is there a viable business that can be built in the future around this Submission? How adept is the team building the product to execute on the vision?

## Scoring rubric for candidate ideas (1-5 each)
Evidence (problem provably real, current 2025-2026) / Niche-specificity (named, reachable user group) /
Big-co neglect (credible reason incumbents won't build it) / Solo feasibility (14-day MVP) / Demo-ability (3-min demo lands) /
Judging fit (6 criteria above) / Whitespace (no one already ships this).

## Research rules
- Never invent links, numbers, quotes, or product names. Mark every source VERIFIED (you fetched it) or UNVERIFIED (search snippet only).
- Prefer 2025-2026 sources. Knowledge may be stale: check that remembered facts are still true as of Sept 2026
  (projects shut down, features shipped, programs disabled/re-enabled, etc.).
- Research only. Do not write code.
